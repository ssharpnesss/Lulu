# Lulu
Lulu moderator and chat manager

Приветствие настраивается администратором отдельно для каждого чата:

```text
Лулу настройки приветствие <tg-emoji emoji-id="5278611606756942667">❤️</tg-emoji> Привет! {имя}
```

Подстановки: `{имя}`, `{фамилия}`, `{ид}`, `{айди}`, `{имяфамилия}`.
Если фамилии нет, подставляется пустая строка. Имена экранируются для HTML.
Поддерживаются буквальный HTML и форматирование сообщения средствами Telegram,
включая пользовательские эмодзи. Регистр, переносы строк и пробелы внутри текста сохраняются.

Бот сначала показывает предпросмотр; если Telegram принимает форматирование,
сохраняет шаблон и включает приветствия для новых участников. Боты не приветствуются.
Выключение: `Лулу защита приветствие выкл`; включение сохранённого шаблона:
`Лулу защита приветствие вкл`.

При следующем запуске поле `chats.welcome_template` автоматически добавляется
в существующую базу. Старые записи и настройки сохраняются. При откате к предыдущему
коду поле можно оставить: оно nullable и не мешает старым читателям и писателям.
Удалять поле или данные для отката не требуется.

Администратор чата может включить антиспам командой `Лулу защита антиспам вкл`
и выключить командой `Лулу защита антиспам выкл`.

Модель возвращает оценку вероятности спама от 0 до 1. Порог удаления по умолчанию —
0.9; его можно изменить в `config.toml`:

```toml
[bot]
spam_threshold = 0.9
```

Это уверенность модели, а не откалиброванная вероятность. На сохранённом тесте
из 10 000 сообщений повышение порога с 0.5 до 0.9 уменьшило ложные блокировки
с 151 до 61, но увеличило пропущенный спам с 204 до 358.
Подробные метрики: `training/v02/threshold_comparison.json`.

Проверка команд, прав администратора и порога:
`poetry run python -m unittest discover -s tests -p test_commands_and_spam.py`.
